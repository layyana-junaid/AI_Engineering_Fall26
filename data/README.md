# Data

Dataset: **Tiny Shakespeare** (~1.1 MB, ~40,000 lines, 1,115,394 characters).
Source: Hugging Face dataset card `karpathy/tiny_shakespeare`; plain text mirror at
https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt

Download (done automatically on first run if the file is missing):

    python -m src.dataset --download

The file is not committed (see .gitignore).
